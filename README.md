# Exemple de mise en place d'un projet python


### Création du .venv
```
py -m venv .venv
```

### Activation du .venv
Windows
```
.venv\scripts\activate
```

Linux
```
source .venv/bin/activate
```

### Récupérer les dépendances et le installer dans le .venv
```
pip install -r requirements.txt
```
